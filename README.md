# BRIONIX SYSTEMS - Official Website

**Engineering Intelligent Systems**

Official digital presence of BRIONIX SYSTEMS. A premium website showcasing intelligent systems design, AI expertise, and enterprise solutions.

## 🎯 Vision

A website that immediately conveys: *"This company knows exactly what it does."*

Designed to feel like Apple, OpenAI, Stripe, and Linear collaborated on it.

## 🏗️ Tech Stack

- **React 18** + **TypeScript** - Type-safe UI
- **Vite** - Lightning-fast development & building
- **TailwindCSS** - Utility-first design system
- **Framer Motion** - Smooth, elegant animations
- **Firebase** - Backend, auth & hosting
- **React Router v6** - Client-side routing
- **Lucide Icons** - Premium icon system

## 🎨 Design System

**Brand Colors**:
- Background: `#05070D` (Deep Navy)
- Primary Blue: `#2563EB`
- Electric Blue: `#3B82F6`
- White: `#FFFFFF`
- Light Gray: `#CBD5E1`
- Dark Gray: `#1E293B`

**Typography**: Inter / Geist

**Philosophy**: Maximum whitespace, smooth animations, subtle glassmorphism, discrete shadows

## 📁 Project Structure

```
brionix-web/
├── src/
│   ├── components/        # Reusable UI components
│   │   ├── common/       # Shared components (Header, Footer, etc)
│   │   ├── sections/     # Page sections
│   │   └── ui/           # Base UI components
│   ├── layouts/          # Page layouts (MainLayout, etc)
│   ├── pages/            # Page components
│   ├── hooks/            # Custom React hooks
│   ├── services/         # Business logic & APIs
│   ├── firebase/         # Firebase config & services
│   ├── styles/           # Global styles & tailwind config
│   ├── types/            # TypeScript type definitions
│   ├── assets/           # Images, fonts, SVGs
│   ├── utils/            # Utility functions
│   ├── animations/       # Framer Motion animations
│   ├── config/           # App configuration
│   ├── App.tsx           # Main app component
│   └── main.tsx          # Entry point
├── public/               # Static assets
├── index.html            # HTML template
├── package.json
├── tsconfig.json
├── tailwind.config.js
├── vite.config.ts
├── .env.example
└── .gitignore
```

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Type checking
npm run type-check

# Linting
npm run lint
```
