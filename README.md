# BRIONIX SYSTEMS — Official Website

Sitio corporativo en React 18 + TypeScript + Vite.

## Unidades
1. Servicios profesionales: consultoría, marketing, diseño digital y soporte técnico.
2. Soluciones comerciales: puntos de venta, hardware y equipamiento.
3. Productos digitales: ebooks, guías y recursos descargables.
4. IA e investigación: investigación, desarrollo e integración tecnológica. Los proyectos muestran su estado real.

```bash

npm run build
npm run preview
```

## Formulario
El formulario valida los campos en el navegador y prepara un mensaje para WhatsApp. No almacena solicitudes en una base de datos ni envía correo automáticamente. Para producción, conectar un backend seguro (por ejemplo Firebase Functions + Firestore) y notificaciones por correo, además de aviso de privacidad y consentimiento.
